MIDNIGHT VAULT — an original top-down 2D canvas stealth heist. Cross three museum rooms past patrolling guards with visible vision cones and sweeping security cameras, lift the Star Sapphire, and slip out the green exit before the alarm meter fills. Tools cost charges (smoke, EMP, coin toss); small loot pays charges back. Pure HTML/CSS/JS, no dependencies, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — move with WASD / arrow keys (Shift to sneak), or click anywhere to walk there. Tools: 1 smoke, 2 EMP, 3 coin toss.
